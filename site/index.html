super-statusline

A Claude Code statusline you design in your browser, against your real session.

Try the live demo Install

Install

  1. Add the plugin in a terminal:

    claude plugin marketplace add jinhuang712/claude-code-super-statusline
claude plugin install super-statusline@claude-code-super-statusline

  2. In Claude Code, run:

    /super-statusline:config

  3. Pick a layout in the page that opens. Every change saves by itself.

Needs Claude Code 2.1.251+ and Bun. More in INSTALL.md.

What you can change

  • Layout

    Minimal, Standard or Full — or Custom, to build your own lines.

  • Color theme

    default, nord, dracula, gruvbox, tokyo-night, catppuccin, mono.

  • Progress bars

    Eight bar styles, coloured by thresholds or a smooth gradient.

  • Separator

    │ · • / ❯ — or your own.

  • Every widget

    Label, colour and its own options, right under its line.

  • Your own widgets

    Drop a .ts file in a folder; it shows up in the page.
