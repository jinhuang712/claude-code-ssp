Every widget is a chip. Drag chips between lines and zones — the preview redraws on every drop.

  1. 01

    Drag from the tray

    Pull any of the 39 widgets onto a line, into its left or right zone.

  2. 02

    Drag to rearrange

    Reorder within a line or move to another. From the keyboard: focus a chip, then Alt + arrow keys.

  3. 03

    Drag back to remove

    Drop it on the tray and it leaves the statusline.

0403 · Install

Two commands. Then it’s yours.

Needs Claude Code 2.1.251 or later and Bun on your PATH.

TERMINAL 
$ claude plugin marketplace add jinhuang712/claude-code-super-statusline
$ claude plugin install super-statusline@claude-code-super-statusline

Then run /super-statusline:config in Claude Code and pick a layout.
