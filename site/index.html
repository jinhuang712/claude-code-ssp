super-statusline

A Claude Code statusline you design in your browser. Start from a preset, then drag widgets where you want them.

claude plugin marketplace add jinhuang712/claude-code-super-statusline
claude plugin install super-statusline@claude-code-super-statusline

Then run /super-statusline:config in Claude Code. Needs Bun.

Try it — this is the real configurator

  • Drag a widget from Unused widgets onto any line, left or right.
  • Drag it again to reorder, or move it to another line — or focus it and press Alt + arrow keys.
  • Drag it back to the tray to remove it.
